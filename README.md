# Explorando os Recursos de IA Generativa com Copilot e OpenAI

Este repositório contém anotações e práticas realizadas com base na aula [Explorando os Recursos de IA Generativa com Copilot e OpenAI](https://web.dio.me/lab/explorando-os-recursos-de-ia-generativa-com-copilot-e-openai/learning/1a2619f1-4d92-435a-b010-3baef67cae55?back=/track/xp-inc-cloud-com-inteligencia-artificial) da DIO.  
O objetivo é aplicar e consolidar os conhecimentos sobre IA generativa, GitHub Copilot e os serviços do Azure OpenAI.

---

## O que é IA Generativa

A Inteligência Artificial Generativa é um ramo da IA focado na criação de novos conteúdos a partir de dados existentes.  
Utilizando modelos de aprendizado profundo, como os Modelos de Linguagem de Grande Escala (LLMs), a IA generativa é capaz de produzir:

- Textos em linguagem natural  
- Códigos de programação  
- Imagens  
- Músicas  
- Vídeos  

Esses modelos aprendem padrões e estruturas dos dados de treinamento para gerar saídas coerentes e contextualmente relevantes.

---

## Ferramentas Utilizadas

### GitHub Copilot

O GitHub Copilot é uma ferramenta de IA desenvolvida pela GitHub em parceria com a OpenAI.  
Ele atua como um assistente de codificação, sugerindo trechos de código e completando funções com base em comentários e no código escrito.  
Alimentado pelo modelo OpenAI Codex, o Copilot suporta diversas linguagens de programação e integra-se a ambientes como o Visual Studio Code.

### Azure OpenAI Service

O Azure OpenAI Service permite o acesso aos modelos avançados da OpenAI através da infraestrutura da Microsoft Azure.  
Com ele, é possível integrar capacidades de IA generativa em aplicações, como:

- Geração de texto e resumo  
- Análise de sentimentos  
- Tradução automática  
- Geração de código  

Para utilizar o serviço, é necessário:

1. Acessar o portal do Azure  
2. Criar um recurso do Azure OpenAI  
3. Selecionar e implantar o modelo desejado  
4. Configurar as credenciais de acesso

## Laboratório Prático

Durante a aula, foi realizado um laboratório prático com os seguintes passos:

1. Configuração do Ambiente: Instalação e configuração do Visual Studio Code com a extensão do GitHub Copilot.  
2. Exploração do Copilot: Utilização do Copilot para sugerir e completar códigos em diferentes linguagens.  
3. Integração com Azure OpenAI: Criação de um recurso no Azure OpenAI e teste de geração de texto através da API.  
4. Análise de Resultados: Avaliação das respostas geradas pela IA e ajustes nos prompts para obter melhores resultados.
