 Ferramentas Utilizadas
GitHub Copilot
O GitHub Copilot é uma ferramenta de IA desenvolvida pela GitHub em parceria com a OpenAI. Ele atua como um assistente de codificação, sugerindo trechos de código e completando funções com base em comentários e no código escrito. Alimentado pelo modelo OpenAI Codex, o Copilot suporta diversas linguagens de programação e integra-se a ambientes como o Visual Studio Code.

Azure OpenAI Service
O Azure OpenAI Service permite o acesso aos modelos avançados da OpenAI através da infraestrutura da Microsoft Azure. Com ele, é possível integrar capacidades de IA generativa em aplicações, como:

Geração de texto e resumo

Análise de sentimentos

Tradução automática

Geração de código

 Laboratório Prático
Durante a aula, foi realizado um laboratório prático com os seguintes passos:

Configuração do Ambiente: Instalação e configuração do Visual Studio Code com a extensão do GitHub Copilot.

Exploração do Copilot: Utilização do Copilot para sugerir e completar códigos em diferentes linguagens.

Integração com Azure OpenAI: Criação de um recurso no Azure OpenAI e teste de geração de texto através da API.

Análise de Resultados: Avaliação das respostas geradas pela IA e ajustes nos prompts para obter melhores resultados.
